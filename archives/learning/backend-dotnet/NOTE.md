## Why it was cut

The .NET half existed for exactly one reason: management wanted Tarun .NET-ready so they could
shortlist him internally for a new .NET project.

**He resigns 7 September.** Internal shortlisting is worth nothing to someone leaving in three weeks,
and every hour it cost was an hour taken from the 15 November offer floor. The interview stack is
Node.js.

**Cutting it gained 17 days.** `mission/plan.md` had Node starting 1 September as phase A2. It started
17 August instead.

## The argument that died with it

`mission/plan.md` used to carry a paragraph titled *"August's .NET is not wasted, if you frame it
right"* — the idea that .NET could run as the `X` (explain) half of each concept pair so September's
Node would only be the `W` (write) half of concepts already understood. That was a genuinely good
argument **for keeping a block that had already been paid for.** It is not an argument for spending
new hours on it, and once the block was cut the premise went with it. It has been deleted from
`plan.md`. Do not restore it.

## The forfeit, recorded honestly

This was a trade, not a free win. If anyone at work asked about .NET progress before 7 Sept, the
answer was "nothing". That was accepted knowingly on 2026-08-15.

## What was kept

Everything in `profile.md` about **how Tarun performs** survived the cut and lives on in the rebuilt
track — the run-gate failure ("done" without running the code), correction-persistence, reading a
spec's example as a literal, fixing the function and forgetting the caller. Those findings are
stack-independent and were the most valuable thing the .NET sessions produced.

The `.review` planted-bug component also survived, retargeted from C# bugs to Node/Postgres ones.

## If .NET ever comes back

It does not come back for this employer. If a *future* job needs it, start from
`references/cv/master.tex` and the fact-bank rather than from this material — and note that the C# 7.3
/ .NET Framework 4.8 ceiling these lessons were written against was a constraint of that one
workplace, not of .NET.
