# Monthly summaries

One file per month (`YYYY-MM.md`), written by `/daily-log` at month-end when it compresses
that month's daily log. This is the **retained** record — the granular daily entries are
archived to `archives/daily/YYYY-MM.md` and the active `daily/log.md` is reset clean.

Each summary captures, for the month: blocks-hit rate per block, streaks, the biggest wins,
the recurring misses (and their real cause), and 1–2 adjustments to carry into next month.
