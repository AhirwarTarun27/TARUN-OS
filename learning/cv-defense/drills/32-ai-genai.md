## Teach block (read once, then close)

### 1. The split — draw it before they do

> *"Two different things sit under that heading. At work I built the portal on top of an AI pipeline —
> I consumed it, I didn't write it. Separately, I've built my own agentic development system, and that
> one is entirely mine."*

Saying this unprompted costs ten seconds and removes the only real trap on the line.

### 2. The employer half — DentScribe, and what you legitimately know

You can go two levels deep here because you built against it (`../../project-knowledge-base/dentscribe/02-ai-pipeline.md`):

- **SNS → SQS → worker.** Minutes of work, so it can't be a request-response call.
- **Two LLM calls: analyse, then format.** Reasoning and strict-JSON emission degrade each other in one
  call. They were A/B-ing a single-call path behind an env flag.
- **The prompt is grounded in chart data**, not just the audio — the PMS is called inside the pipeline.
- **Every prompt and intermediate output is archived to S3.** It's a medical record generated by a
  model; when a clinician disputes a note you need the exact input. **That's the answer that shows
  domain understanding.**
- **`paused`** as a first-class state, so a pipeline failure is visible and recoverable rather than an
  eternal spinner.

**Then the boundary:** *"I didn't write the transcription workers, the prompts, or the integration."*

### 3. The personal half — answer concretely, never abstractly

`defend-map.md` flags this: **expect "what does orchestrating an agentic workflow actually mean?"**
Most candidates say this phrase and mean nothing. Answer with mechanisms:

- **Skills** — a task-specific instruction set loaded on demand, so the agent isn't carrying twenty
  workflows it doesn't need.
- **Subagents** — scoped workers (`kit-researcher`, `listing-researcher`) with their own tool
  allow-lists, that return a result instead of a transcript.
- **MCP** — the protocol for giving a model tools and data. **And a real policy decision you made:**
  doc-reference MCPs get *cached to a local file* instead of installed, because paying a live
  round-trip for knowledge that barely changes is waste. **Action MCPs get installed, because a file
  can't run a command.** *That distinction is a genuine piece of engineering judgment and it's the best
  thing you can say on this whole line.*
- **Context engineering** — fixed read budgets per session; trackers **rewritten rather than appended**
  so cost is constant in month six; one file per fact.

### 4. Context engineering — the concrete version

> *"The naive version of a long-running assistant appends to a log, so month six costs six times month
> one and most of it is stale. So the trackers get rewritten in place, not appended. Sessions have a
> declared read budget — this file, that file, stop. Depth lives in one place and is referenced, never
> duplicated. It's the same instinct as keeping a bundle small: decide what doesn't need to be there."*

**The bundle analogy is worth keeping.** It converts an AI buzzword into an engineering habit an
interviewer already respects.

### 5. What to say about AI-assisted development — the standout answer

You're certified on Copilot and use Claude Code daily. But the answer that lands is the **opposite** one:

> *"I built myself a machine-coding practice lab that deliberately disables autocomplete, because
> AI-assisted coding was eating the blank-file-to-structure muscle I need in an interview. I use these
> tools heavily and I also protect the skills they erode."*

**That is a better answer than any tool list**, because it demonstrates judgment about the tools rather
than enthusiasm for them. It's true, it's specific, and almost nobody says it.

### 6. If they ask about RAG, fine-tuning, or evals

**Don't bluff.** Honest positions — the fuller versions, with the trap follow-ups, are in
`../../ai-fluency/survival-sheet.md` §8, §11 and §12:
- **RAG** — you understand the shape (retrieve relevant context, put it in the prompt) and you've done
  the non-vector version: the DentScribe pipeline injects chart data. **You haven't run a vector store
  in production.**
- **Fine-tuning** — not something you've done. Say so and move.
- **Evals** — *"the honest gap. The pipeline archived every prompt to S3, which is what you'd need to
  build evals on, but I didn't build the evaluation layer."* **Naming what the S3 archive would enable
  turns a gap into a systems answer.**

## Grading key — *Claude only*

- **Q1 fails without the split** — employer = integration, personal = built. Both halves named.
- Q2-4 → queue, two calls, grounded prompt, S3 archive, `paused`. **Boundary must be stated
  unprompted.** Q4's answer is auditability of a model-generated medical record — that's full marks.
- Q5-6 → **mechanisms, not adjectives.** Deduct hard for abstraction. Full marks on Q6 needs the
  **doc-MCP vs action-MCP policy**, which is his own judgment call.
- Q7 → rewritten-not-appended, read budgets, constant cost in month six. The bundle analogy is a bonus.
- **Q8 fails on any bluff.** *"I've injected retrieved context; I haven't run a vector store"* and
  *"I didn't build evals, though the S3 prompt archive is what you'd build them on"* are both full marks.

**Coverage gate:** the split stated, pipeline boundary landed, one concrete agentic mechanism, no bluff
on RAG/evals.
