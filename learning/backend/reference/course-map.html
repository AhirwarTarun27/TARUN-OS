The one thing this course is for

The CV already sells this stack. cv-defense/skills-defense.md grades Node, Express, REST, PostgreSQL and Sequelize 🟢 anchored. So the job here is not to learn backend into a vacuum. It is to close the gap between what the résumé claims and what the hands can do, before somebody tests it.

scheduled ingestion → PostgreSQL → Express REST → ownership-scoped queries

That is the build, and it is deliberately the same shape as CloudForestX. One project, grown across all 32 sessions, never restarted.
