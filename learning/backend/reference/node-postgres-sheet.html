Setup, once

Verified on this machine 2026-08-15: Node v20.20.0, Docker Desktop present, psql not installed.

# in backend-lab/ — start the database
docker compose up -d

# a psql shell, without installing psql on Windows
docker compose exec db psql -U postgres -d costlab

# wipe it and start clean (this is why we use Docker)
docker compose down -v && docker compose up -d

what you write

Deliberately set to "nothing"

null
The key is not on the object at all
→
!('k' in obj)
!x is not a null check. 0, '' and false are all falsy and all valid values. Use == null, which catches null and undefined and nothing else.

The SQL half of this lands at S8, and it is a better pairing than the one it replaced: in SQL, NULL is not equal to anything, including itself. So WHERE col = NULL is never true and never errors — it silently returns zero rows. You write IS NULL.
