# Mission: Frontend Interview Q&A (JS + React)

## Why
Tarun is in an active job switch (frontend-heavy full-stack, 2-3 month target from 2026-07-07).
The "232 Interview Questions" ebook is the exact question bank interviewers pull from. The goal is
to walk into interviews able to answer any of these cold — theory out loud, tricky output predicted,
and small problems coded live — not just recognize the topic.

## Success looks like
- Answer any JS-theory question from the bank out loud, with a one-line example, no fumbling.
- Predict the output of the coercion / closure / event-loop trick questions and explain *why*.
- Code the 27 JS problems + React scenario/machine-coding tasks from a blank editor.
- Explain every core React concept (hooks, rendering, patterns) and when to reach for each.

## Constraints
- Level: rebuilding fundamentals from the ground up — clean re-teach, assume nothing.
- Lesson size: medium (~8-10 questions, ~20 min per sitting).
- Learning must FLOW: gradually increasing difficulty, each lesson building on the last, no
  forward-references to unexplained keywords. Connect every dot.
- All generated HTML is dark-themed (light hurts his eyes).

## Out of scope
- The 20 Angular scenario questions — React is the core library. Skip entirely.
- System design (separate `learning/` track).
