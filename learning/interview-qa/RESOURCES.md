# Frontend Interview Q&A Resources

The ebook (`reference/232Questions.pdf`) is the *question set* — what gets asked. These are the
*answer sources* — high-trust references we ground explanations in, so we're never repeating the
ebook's occasional shortcuts or typos.

## Knowledge

- [MDN Web Docs — JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
  The canonical reference. Use for: exact behavior of any built-in, coercion rules, method signatures.
- [javascript.info — The Modern JavaScript Tutorial](https://javascript.info/)
  Best structured deep-dives with runnable examples. Use for: closures, `this`, prototypes, event loop, promises.
- [You Don't Know JS Yet — Kyle Simpson (free, GitHub)](https://github.com/getify/You-Dont-Know-JS)
  Mental models over trivia. Use for: scope & closures, coercion, `this` & object prototypes.
- [React docs — react.dev](https://react.dev/)
  The official, hooks-first docs. Use for: any React concept, especially the "Learn" + "Reference" split and the `useEffect` guidance.
- [Jake Archibald — "In The Loop" (event loop talk)](https://www.youtube.com/watch?v=cCOL7MC4Pl0)
  The definitive visual explanation of the event loop, tasks vs microtasks. Use for: async output questions.
- [MDN — Equality comparisons and sameness](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Equality_comparisons_and_sameness)
  The `==` vs `===` vs `Object.is` table. Use for: the coercion trick questions.

## Wisdom (Communities)

- [r/reactjs](https://reddit.com/r/reactjs) — high-signal, well-moderated. Use for: pattern critique, "is this idiomatic" checks.
- [r/learnjavascript](https://reddit.com/r/learnjavascript) — use for: "why does this output X" sanity checks before an interview.
- Mock interviews: [Pramp](https://www.pramp.com/) / peer mocks — use for: saying answers OUT LOUD under pressure (the real gap the ebook can't close).
