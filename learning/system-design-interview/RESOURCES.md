## Knowledge — the backbone

- [Book: _System Design Interview – An Insider's Guide, Vol 1_ — Alex Xu](https://www.amazon.com/dp/B08CMF2CQF)
  The canonical text this whole track follows. Use for: every chapter — read the chapter after the video, before the lesson.
- [ByteByteGo — course page: Scale From Zero To Millions Of Users](https://bytebytego.com/courses/system-design-interview/scale-from-zero-to-millions-of-users)
  The free web version of Chapter 1, by Alex Xu, mirrors the book almost 1:1. Use for: the canonical read for Lesson 1.
- [ByteByteGo — YouTube channel](https://www.youtube.com/@ByteByteGo)
  Alex Xu & Sahn Lam. Highest-trust videos; visuals often match the book. Use for: priming each chapter (watch-first).
- [Hello Interview — Delivery Framework](https://www.hellointerview.com/learn/system-design/in-a-hurry/delivery)
  Built by FAANG hiring managers. The best "how to actually run the 45 minutes" resource. Use for: Ch 3 framework + presenting.
- [Hello Interview — YouTube channel](https://www.youtube.com/@hello_interview)
  Modern deep-dive walkthroughs. Use for: "can I present this?" — Ch 8 (Bitly), Ch 14 (YouTube), and deep dives.
- [ByteByteGo — EP46: Step-by-step guide on system design interviews](https://blog.bytebytego.com/p/ep46-step-by-step-guide-on-system)
  Newsletter version of the 4-step framework. Use for: Ch 3, quick framework refresher.
