# Starting Python with strong JavaScript and zero Python

Tarun is a working JS/React developer with no Python. His JavaScript fundamentals were rebuilt and drilled
in `learning/interview-qa/` (types and coercion, scope and hoisting, closures, `this`, objects and
prototypes, arrays), so those are the comparisons that will land. He is new to the AI field, so AI
terms need plain explanations even when the Python is easy.

**Implications**
- Teach Python as *differences from JS*, not from zero. The fastest wins are the places JS is lenient
  and Python is strict: `"1" + 1`, wrong argument counts, indentation.
- His known weak spot from the JS course is **naming the error / the rule**, not understanding it.
  Ask for the label (`TypeError`, `NameError`, `IndentationError`) in drills, not just the output.
- Don't assume AI vocabulary (model, prompt, tool, SDK). Define it the first time it appears.
