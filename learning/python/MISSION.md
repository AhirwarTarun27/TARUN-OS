# Mission: Python, as a JavaScript developer moving into AI engineering

## Why
Python is the language of the AI layer. Tarun wants to become an AI Engineer (goal set 2026-10-02), and
Ed Donner's AI Engineer Core Track plus FastAPI backends both assume he can read and write Python.
He already knows JavaScript well, so this course is a bridge, not a from-zero course.

## Success looks like
- Finish all 17 concepts of the Exercism Python track, doing every learning exercise by hand.
- Read a Python file from an AI course and know what every line does, without looking anything up.
- Write a small function from scratch: name it right, call it right, document it with a docstring.
- Know the bridge topics Exercism skips (f-strings, keyword args, comprehensions, `try`/`except`,
  imports and `pip`, JSON, type hints, `async`), so day 1 of Ed Donner's course doesn't feel foreign.

## Constraints
- **Exercism is the only Python resource he follows.** No jumping between sites. The lessons here
  re-teach each Exercism chapter for a JS developer; Exercism supplies the exercises.
- New to the AI field. Plain words, every new term explained, JS comparison wherever one exists.
- He sends chapter links one at a time. One lesson per chapter.
- No AI autocomplete during Exercism exercises. Written by hand.

## Out of scope
- Django, data science / pandas / NumPy, notebooks-as-a-topic.
- DSA in Python (for now).
- Python internals (bytecode, the GIL) beyond a one-line FAQ answer.
