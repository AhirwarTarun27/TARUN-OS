Python for a JS developer · Reference

Glossary

Every new word in the course, in plain English, with the JS equivalent where there is one. The lessons use these exact meanings. Grouped by the lesson that introduced the word.

From Lesson 1 · Basics

Name / binding
A name is Python's word for a variable. Binding means sticking a name on a value with =. a variable that holds a reference
Object
Any value in Python: a number, a string, a function, None. Every object has a type and can have methods.wider than JS's "object". In Python even 42 is one
Dynamically typed
A name can point at any type, and change type later. Types are checked while the program runs. same as JS
Strongly typed
Python won't quietly convert one type into another. "1" + 1 is an error. the opposite of JS coercion
Duck typing
Python cares whether a value has the method you call, not what its type is called. how JS works too: if .map exists, you can call it
Type hints (gradual typing)
Optional labels like def ask(question: str) -> str:. Python itself doesn't enforce them. Tools and libraries read them. You can add them bit by bit. like TypeScript annotations, except Python runs fine without checking them
Interpreter
The program that runs your code, python. It compiles your file to an in-between form and runs that, so "compiled or interpreted?" is "both".like node
REPL
Read, Evaluate, Print, Loop: the >>> prompt. It shows each result, except None.the browser console
Module / module level
A module is a .py file. Module level = the top of the file, outside any function. a JS module and its top-level scope
Block / significant indentation
A group of lines that belong together. Marked by a colon and indentation, and the indentation changes what the code does.what { } do
PEP (8, 257, 20)
Python Enhancement Proposal, an official numbered document. 8 = style, 257 = docstrings, 20 = the Zen of Python (import this).roughly TC39 proposals plus a style guide
snake_case / SCREAMING_SNAKE_CASE
bake_time for variables and functions. EXPECTED_BAKE_TIME for constants. replaces camelCase
Docstring
A triple-quoted string as the first line of a function. Python keeps it as __doc__. JSDoc, but the running program can see it
Dunder
"Double underscore". __doc__, __init__: special names Python uses itself. a bit like __proto__
None
The one "no value" value. Functions without return give it back. null and undefined, merged
TypeError
Wrong kind of value for an operation, or the wrong number of arguments. TypeError, but raised far more often
NameError
Using a name that was never assigned. Usually a typo.ReferenceError
IndentationError
The spaces at the start of a line are wrong. The file won't run.no equivalent
Argument vs parameter
Parameter = the name in the def line. Argument = the value passed in the call. same as JS
Positional argument
An argument matched to a parameter by its position: first value to first parameter. The other kind, passing by name, comes in a later bridge lesson.every JS argument is positional
str
Python's string type. str(1) converts to "1". String, and String(1)
Method
A function that belongs to a type and is called with a dot, like .upper(). same as JS
int / NoneType
int = whole numbers. NoneType = the type of None, its only value. JS has one number type; Python splits whole numbers from decimals
Callable
Anything you can call with ()."something you can invoke"
Imperative / functional / object-oriented
Step-by-step instructions / passing data through functions / grouping data and methods in classes. Python supports all three.the same three styles you mix in JS
Model / tool / SDK AI words
Model = the AI that reads text and replies. Tool = a function the model may ask to run. SDK = a company's library for calling their service from code.an SDK is like an npm client package

From Lesson 2 · Bools

bool / Boolean
The type with only True and False.boolean
Operator / operand
The operator does the work (and, +). The operands are the values it works on. same words
Keyword
A word Python reserves for itself (and, def, True, None). You can't use it as a name.reserved words
SyntaxError
Python can't read the line, so nothing in the file runs.same name
Precedence
The order operators run in: comparisons, then not, then and, then or. Brackets beat everything.same idea; not sits lower than !
Short-circuit evaluation
Stopping once the answer is known, so the right side of and/or may never run. same as && / ||
Truthy / falsy
Falsy = False, None, zero, anything empty. Everything else is truthy. [] and {} are truthy in JS, falsy in Python
bool()
Turns any value into True/False by the truthiness rule.Boolean(x)
List / dict
[1, 2] ordered collection / {"k": "v"} values under keys.array / plain object
Subclass
A special version of another type that keeps its behaviour. bool is a subclass of int. extends
is (identity)
Same object, not just equal value. Use it for None; use == for values. === on objects
isinstance()
"Is this value a kind of that type?"instanceof
Warning
Something looks wrong, but the code still runs. An error stops it.console.warn / linter warning
Literal
A value typed straight into the code: 1, "hi", True.same word
pass
A do-nothing statement that fills a body that would otherwise be empty.empty { }
Stub
A function with name, parameters and docstring but no real body yet.placeholder function

From Lesson 3 · Numbers

int / float
Whole number / number with a decimal point. Mixing them gives a float.both are number in JS
Arbitrary precision
No size limit. Python ints stay exact however big they get.BigInt
Widening
An int meeting a float becomes a float, the "wider" type.no equivalent
complex
A number type for imaginary-number maths (2 + 3j). Not needed for app code.no equivalent
Floor division (//)
Divide, then round down. Float in → float out.Math.floor(a / b)
Modulo (%)
The remainder after dividing.same, but differs for negatives
Exponentiation (**)
Raising to a power.same **
Binary / unary operator
Binary takes two values (a + b). Unary takes one (-2).same words
ZeroDivisionError
Dividing by zero with /, // or %.JS returns Infinity
Type conversion / casting
Changing a value's type on purpose: int(), float(), str().Number(), String()
ValueError
Right type, wrong value: int("abc").JS gives NaN
Truncate
Cut off decimals without rounding.Math.trunc()
Round half to even
Exact halves round to the even neighbour: round(2.5) → 2.Math.round rounds .5 up
PEMDAS / BODMAS
Brackets, powers, then * / // %, then + -. Operators in the same step are a tie: go left to right, not by letter.same order
Floating-point error
Tiny inaccuracy because most decimals can't be stored exactly. Don't use == on floats.identical in JS
assertAlmostEqual
A test check that passes when floats match to about 7 decimal places.Jest toBeCloseTo
Standard library / import
Tools that ship with Python, switched on with import.Node built-in modules
Decimal / Fraction
Exact decimal and exact fraction types from the standard library.a library in JS

From Lesson 4 · Conditionals

Conditional / if statement
Code that only runs when a test is true.JS if
Condition
The test after if. Ends in True or False.the part in ( )
Branch
One possible path through a conditional.same word
Control flow
The order lines run in, and which get skipped.same idea
elif
"Else if". Only the first true branch in a chain runs.else if
Boundary / edge case
The value where the answer switches, and the values just around it. Test those first.same idea
switch / match
No switch in Python: use elif. match is a newer tool, taught later.switch
Mutually exclusive
If one is true, the others can't be. Use one elif chain.same idea
Early return
Returning from inside a branch, so later ifs act like elif.same pattern
Linter
A tool that flags style problems without running the code.ESLint
Boolean context
A place that needs True/False, like after if. Other values go through bool().same idea
Chained comparison
a < b < c means a < b and b < c.JS gives a different answer
Nested conditional
An if inside an if. Often flattened with and.same
Expression / statement
An expression is a value (2 + 3). A statement does something (if, return).same split
Conditional expression / ternary
yes if test else no.test ? yes : no
Exception
An error object that stops the code and reports what went wrong.Error
raise
Creates an exception: raise ValueError("msg").throw
Traceback
Python's error report. Read from the bottom.stack trace
Guard clause
An if at the top that rejects bad input early.same pattern
