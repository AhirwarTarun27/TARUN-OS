## How I Build

**Architecture follows the constraint, not the trend.** GradeJar keeps student records on-device because privacy was the product requirement — not because a server was the hard part.

**Accessibility is a build step, not a review step.** If `axe` isn't in CI, the site isn't accessible — you just haven't found out yet.

**Shipped beats finished.** A repository is a claim. A domain serving traffic is evidence.

**Performance is a feature you can lose in a single commit.** That's what the gates are for.
